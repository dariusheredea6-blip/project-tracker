# PROJECT TRACKER — Prototipo (Fase 1)

Prototipo visual e interactivo (HTML estático). NO es la aplicación final: los datos son de ejemplo y no se guardan.

## Archivos
- index.html — el prototipo
- favicon.png — icono de la pestaña del navegador
- assets/logo-horizontal.png y assets/icono.png — logotipos originales (recortes exactos)

## Probar en local
Abre index.html con doble clic en el navegador.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (p. ej. project-tracker).
2. Sube TODO el contenido de esta carpeta a la raíz del repositorio (index.html debe quedar en la raíz).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, carpeta / (root) > Save.
4. Espera 1-2 minutos: https://TU_USUARIO.github.io/project-tracker/

## Favicon
En el <head> de index.html: <link rel="icon" type="image/png" href="favicon.png">
Para cambiarlo, sustituye favicon.png por otra imagen cuadrada con el mismo nombre.
